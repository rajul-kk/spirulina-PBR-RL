# tools/

| path | what it does |
|---|---|
| `config_studio/` | Local web UI for editing and previewing run configurations (see its README). |
| `visualize_growth.py` | Plots two rule-based policies' biomass and nutrient curves. `python tools/visualize_growth.py` |
| `report/format_docx.py` | Formats the coursework `.docx` builds. Run from `docs/coursework/`. |
| `report/word_count.py`, `report/word_count_body.py` | Word counts for the coursework reports. Run from `docs/coursework/`. |
